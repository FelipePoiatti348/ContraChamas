# ContraChamas – Mini Site Institucional

## Descrição
Mini site desenvolvido para simular solicitações de serviços para uma empresa, com foco em estrutura HTML e organização de conteúdo para aplicações web.

## Funcionalidades
- Página institucional
- Estrutura de formulário para solicitações
- Organização semântica de conteúdo

## Tecnologias utilizadas
- HTML
- Git e GitHub

## Objetivo
Projeto de estudo com foco em desenvolvimento web, estruturação de páginas e fundamentos de aplicações front-end.
